# Building a Personal Website with Vite + React

Creating a personal website is a great way to showcase your work and learn new tools. I chose Vite for its speed and React for its flexibility.

## My Process

1. Set up the project with Vite
2. Designed components with Tailwind CSS
3. Added routing with React Router
4. Deployed to Vercel

## Lessons Learned

- Vite's fast refresh is a game changer
- Tailwind makes styling fun and efficient
- Deployment is easy with modern platforms
